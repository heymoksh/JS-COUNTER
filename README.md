# JavaScript Counter 🔢

A simple counter application built using **HTML and JavaScript**.

The counter allows users to:

- ➕ Increase the count
- ➖ Decrease the count
- 🔄 Reset the count

## 🛠️ Technologies Used

- HTML5
- JavaScript

## 📚 Concepts Practiced

- DOM Manipulation
- Variables
- Functions
- Event Listeners
- Click Events
- Updating HTML content dynamically

## ⚙️ How It Works

- The counter starts at `0`.
- Clicking **Increase** increments the count by `1`.
- Clicking **Decrease** decrements the count by `1`.
- Clicking **Reset** sets the count back to `0`.
- JavaScript updates the displayed counter value after each button click.
